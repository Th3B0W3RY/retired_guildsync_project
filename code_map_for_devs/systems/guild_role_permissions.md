# Guild role permissions

**Storage:** Columns on `guilds` for four Discord roles and boolean capability flags (`permission_role_1_id` … `role_4_*`). The **guild owner** bypasses slot matching: see **`Guild#role_permission_enabled_for?`** (canonical) and **`ApplicationController#role_permission_enabled_for?`** (delegates to the guild with `current_user` when `user` is omitted). Helpers such as **`can_manage_warnings?`** use the controller path.

**Policies / API:** **`GuildPolicy#update_discord_channels?`** calls **`record.role_permission_enabled_for?(user, :can_manage_discord_channels)`**; **`#manage_discord?`** is an alias so **`Api::V1::DiscordController`** channel **GET**/**PATCH** (`authorize @guild, :manage_discord?`) matches web channel management. **`#signup_discord_event_participation?`** gates **`POST …/discord/events/:id/signup`** (owner or **active** member only).
