**Models:** `Alliance`, `AllianceGuild`, `AllianceMember`, …  
**Access:** `RequiresPaidPlanForAllianceFeatures` concern; plan entitlement `alliance_hub` for UI visibility. **`GET /alliances`** and **`GET /alliances/:id`** both run **`require_paid_plan_for_alliance_features`** first: a **Free** user with **no** active **`AllianceMember`** row is redirected to **`dashboard_path`** with **`alliances.errors.plan_required_for_alliance_hub`** (see **`spec/requests/alliances_spec.rb`** index + show examples). **`AlliancesController#set_alliance`** uses **`find_by`**; **`require_alliance_member`** (**`show`** only) sends paid non-members and unknown **`id`** to **`dashboard_path`** + **`controllers.guilds.access_denied`** (**mega #108**).

**Nested routes (`/alliances/:alliance_id/…`):** **`AllianceNestedAccess`** — **`set_alliance`** uses **`find_by`**; unknown **`alliance_id`** or (where the filter runs) non-active **`AllianceMember`** → **`dashboard_path`** + **`controllers.guilds.access_denied`** (single message; no **`Alliance.find`** rescue). Used by messages, polls, events, loot rolls, members, invites, activity feed, join requests (index/accept/decline **`set_alliance`**), disband votes. Do **not** reintroduce a controller-local **`set_alliance`** on included controllers (loot rolls briefly overrode the concern; **mega #109** removed it). **`alliance_polls_spec`** and **`alliance_loot_rolls_spec`** document unknown id + outsider.

**Alliance web chat** (`AllianceMessagesController` / **`alliance_messages/index`**): **`GET …/alliance_messages`** (**`all_members`**) — member chrome **`support_center_url`** (default + custom **`SiteSetting`**, desktop + **`:mobile`** — **changelog 312**). **`GET …`** with **`type=gm`** (guild owner / alliance GM) — same **`support_center_url`** matrix (**changelog 313**). **`POST`** returns append JSON; **`AllianceMessagesChannel`** streams **`alliance_messages:{alliance_id}:{all_members|gm_only}`** (same GM rule as HTML). Stimulus **`alliance-chat`** subscribes; **`connected`**/**`disconnected`** dispatch slows or restores JSON poll (**5s** fallback vs **30s** when Cable is up). Inline script handles **`alliance-chat:message`** with **`lastMessageId`** dedupe (**mega #147**–**#149**). See **`alliance_messages_spec.rb`**, **`alliance_messages_channel_spec.rb`**.

**Alliance web polls** (`AlliancePollsController` / **`alliance_polls/index`** + **`show`**): **`GET …/alliance_polls`** — member chrome **`support_center_url`** (default + custom **`SiteSetting`**, desktop + **`:mobile`** — **changelog 315**). **`GET …/alliance_polls/:id`** — same matrix (**changelog 316**). Guild-level polls and loot rolls (**`/guilds/:id/polls`**, **`/loot_rolls`**) are documented in [`guild_polls_loot_rolls.md`](guild_polls_loot_rolls.md) (**mega #210**). **`AlliancePollsChannel`** uses **`stream_for`** the **`AlliancePoll`** (subscribers must be active **`AllianceMember`**s). **`AlliancePollsChannel.broadcast_vote_update`** runs after successful votes from **web** **`POST …/vote`**, **`DiscordBotService`** (gateway button), and **`DiscordInteractionJob`** (HTTP interactions); Discord paths **rescue** Cable errors so follow-ups still succeed (**mega #152**, **#154**). Stimulus **`alliance-poll-vote`** subscribes with **`alliance_poll_id`** (**mega #151**). **`alliance_polls_spec`**, **`alliance_polls_channel_spec`**.

**Alliance web loot rolls** (`AllianceLootRollsController` / **`alliance_loot_rolls/index`** + **`show`**): **`GET …/alliance_loot_rolls`** — member chrome **`support_center_url`** (default + custom **`SiteSetting`**, desktop + **`:mobile`** — **changelog 317**). **`GET …/alliance_loot_rolls/:id`** — same matrix (**changelog 318**). **`AllianceLootRollsChannel`** + Stimulus **`alliance-loot-roll-live`** on **`alliance_loot_rolls/show`** (**mega #157**). **`alliance_loot_rolls_spec`**, **`alliance_loot_rolls_channel_spec`**.

**Alliance activity feed** (`AllianceActivityFeedsController`): after the plan gate, **`require_alliance_guild_owner`** (`alliance_owner_in_active_guild?`) limits the UI to users who **own** a guild in the alliance. **Free** non-owner members are denied like paid non-owners. A **Free** user who remains **alliance leader** (owns an active alliance guild) passes the plan **exemption** for active **`AllianceMember`** rows and may still use **index**, **CSV export**, and **export.json** — see **`spec/requests/alliance_free_member_access_spec.rb`**. **`GET …/activity_feed`** (HTML **index**) — member chrome **`support_center_url`** (default + custom **`SiteSetting`**, desktop + **`:mobile`** — **changelog 319**). **`export`** / **`export.json`** return attachments / JSON without full layout chrome. **`alliance_activity_feed_spec`**, **`alliance_free_member_access_spec`**.

**Alliance disband votes** (`AllianceDisbandVotesController`): **`require_gm`** (guild owner with an active guild in the alliance). **`RequiresPaidPlanForAllianceFeatures`** applies; retained **Free** alliance **GMs** use the same active-member exemption as other read/participation surfaces. **`GET …/alliance_disband_votes`** — member chrome **`support_center_url`** (default + custom **`SiteSetting`**, desktop + **`:mobile`** — **changelog 320**). **`spec/requests/alliance_disband_votes_spec.rb`**, **`spec/requests/alliance_free_member_access_spec.rb`** — free non-GM denied (**`not_gm`**); **Free** leader **GET**/**POST** with two active guilds (no premature majority disband).

**Alliance web events** (`AllianceEventsController` / **`index`** + **`new`** + **`show`**): **`GET …/alliance_events`** — member chrome **`support_center_url`** (default + custom **`SiteSetting`**, desktop + **`:mobile`** — **changelog 323**). **`GET …/alliance_events/new`** — same matrix (**changelog 321**). **`GET …/alliance_events/:id`** — same matrix for any active alliance member (**changelog 322**). Guild owners may **`POST`** create; non-owner officers are redirected (**`alliance_events_spec`**). Discord broadcast hooks on update/delete (**`AllianceDiscordBroadcastService`**). i18n under **`alliances.events.*`**.

**i18n:** Shared alliance chrome in **`config/locales/{locale}/alliances.{locale}.yml`**. Member directory + tag UI uses **`alliance_members.*`** in **`alliance_members.{locale}.yml`**; alliance-wide polls use **`alliance_polls.*`** in **`alliance_polls.{locale}.yml`** (see **`config/i18n-tasks.yml`** router), including **`alliance_polls.show.vote_noun`** / **`votes_noun`** for live vote result lines (**mega #151**). **`alliances.members.*`** duplicates some copy historically; controllers/views use the **`alliance_members`** / **`alliance_polls`** key trees.

**Guild-scoped owner flows:** **`GuildAllianceJoinRequestsController`** and **`GuildAllianceInvitesController`** use the same membership / ownership **`set_guild`** resolution as **`GuildsController`**; users who cannot access the **`guild_id`** are redirected to **`my_guilds_path`** with **`controllers.guilds.access_denied`** (before **`require_guild_owner!`** or paid-plan checks). **`spec/requests/guild_alliance_join_requests_spec.rb`**, **`spec/requests/guild_alliance_invites_spec.rb`**.
